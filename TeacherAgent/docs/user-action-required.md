# 需要用户操作的事项

最后更新：2026-07-10

以下是自动化开发无法完成、需要用户手动操作或决策的事项。

## 1. 实机验证（必须用户操作）

### 1.1 Tauri 窗口功能验证

启动应用后需要手动验证：

```powershell
npm run tauri:dev
```

验证清单：
- [ ] 左侧导航显示 5 个入口：对话辅导、练习、仪表盘、知识图谱、设置
- [ ] 对话页：输入框可见、可输入、发送按钮可点击
- [ ] 练习页：题目列表显示、点击题目进入练习、提示按钮可用
- [ ] 仪表盘页：掌握度分布显示、统计数据正确
- [ ] 知识图谱页：节点图渲染、点击节点显示详情
- [ ] 设置页：Provider 配置表单可见可输入

### 1.2 Provider 配置

需要用户手动填写：
- Provider 名称
- Base URL（如 `https://api.mimo.com/v1`）
- 模型名称（如 `mimo-v2.5-pro`）
- API Key

操作顺序：
1. 在设置页填写配置
2. 点击"保存本次运行配置"。2026-07-30 前保存的旧 Key 没有 endpoint 绑定，首次使用需重新录入一次；以后 Base URL 变化也必须重新录入 Key。
3. 点击"测试模型连接"

### 1.3 教学链路验证

配置 Provider 后，在对话页测试：
- [ ] `什么是极限？` → 应返回简短解释 + 引导问题
- [ ] `直接告诉我答案` → 应拒绝直接给答案
- [ ] `给我一道夹逼定理练习` → 应展示题目和提示
- [ ] `帮我复盘这道夹逼定理题` → 应展示完整解析

### 1.4 练习模块验证

- [ ] 点击"查看解析"，答案和步骤正确展示

### 1.5 仪表盘验证

- [ ] 统计数据（总练习次数、正确率）与实际一致

### 1.6 知识图谱验证

## 2. 环境依赖（需要用户安装）

### 2.1 Ollama（本地模型，可选）

如需使用本地模型推理：

```powershell
# 安装 Ollama
# 下载地址：https://ollama.com

# 拉取模型
ollama pull qwen2.5:7b

# 验证
ollama list
```

### 2.2 sqlite-vec 扩展（可选，提升向量检索性能）

当前使用纯 Rust 实现的向量搜索（线性扫描），如需 ANN 索引加速：

```powershell
# 需要网络连接到 crates.io
cd src-tauri
cargo add sqlite-vec
```

**注意**：当前环境无法连接 crates.io，此步骤需要网络恢复后执行。

## 3. 架构决策（需要用户确认）

### 3.1 Embedding 模型选型

当前方案：调用 Provider 的 `/v1/embeddings` 端点（需要 Provider 支持）。

替代方案：
- **方案 A**：通过 Ollama 运行本地 embedding 模型（如 `nomic-embed-text`）
- **方案 B**：使用专门的 embedding API（如 OpenAI `text-embedding-3-small`）
- **方案 C**：预计算 seed 数据的 embedding，打包到应用中

建议：优先方案 A（本地、无额外成本），备选方案 B（质量更高）。

### 3.2 多学科扩展优先级

当前只有数学"极限与连续"章节。扩展方向：
- 数学：线性代数、概率论
- 英语：阅读理解、写作
- 其他：法学、会计

建议：先完成数学全科覆盖，再扩展其他学科。

### 3.3 LLM Reflection 实现方式

当前已接入运行链路：有 Provider 配置时异步调用 LLM 反思，失败自动 fallback 到规则版，不阻塞学生可见回复。无 Provider 时使用规则版。
