# Teacher — 隐私优先的多端协同智能学习辅导系统

本仓库包含系统的两个端：

- `TeacherAgent/` — 桌面端（Tauri 2.x + Vue 3 + Rust）：本地知识管线、私有文档 RAG、BKT 知识追踪、局域网同步服务端。
- `AlertTime/` — 手机端（Kotlin + Jetpack Compose）：专注采集、端侧学习分析、局域网同步客户端。

两端通过自设计的局域网 HTTPS 同步协议（证书指纹配对、消息信封严格校验、幂等快照）连接，形成"采集→评估→建议→决策回传"闭环。协议规范与双端测试夹具位于各自仓库的 `sync/protocol/` 目录，内容逐字一致。
